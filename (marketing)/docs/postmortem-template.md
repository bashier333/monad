# Postmortem template (S-851/S-852)

Blameless. Every sev gets one, no exceptions.

1. Summary (2 lines) + severity + duration + who was affected.
2. Timeline (UTC, from logs).
3. Root cause (data causes get a fixture/eval — S-855 note).
4. What went well / what didn't.
5. Action items with owners + dates (tracked to done — S-853 note).
6. Pilot notification (who was told what, when — S-854 note).
7. Public summary for trust where apt (S-859 note: changelog).

Repeat causes reviewed quarterly (S-857 note); quality = specific + dated (S-858 note).
