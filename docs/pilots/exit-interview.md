# Pilot exit interview (B-112) — 20 minutes, founder runs it, verbatim quotes filed

1. Would you pay for this? (Silence. Let them answer.)
2. How much — per month, and what would have to be true to pay double?
3. What would make you leave in the next 90 days?
4. Who else should I talk to — the next carrier this would save?
5. May I quote you (anonymized)? May I name you?

File answers + quotes in the pilot notes the same day. A "maybe" is a no — ask what would
make it a yes, and whether that's on the roadmap or a different product.
