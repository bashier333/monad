# Pilot bug SLA (B-091)

- Acknowledge: <4 hours. Workaround: <24 hours. Fix or rollback plan: <72 hours.
- Every pilot-visible bug gets a GitHub issue from the bug template with `pilot` label.
- The pilot board = GitHub project with columns: reported → workaround → fixed → verified by pilot.
- Wrong figures are different from bugs: they go through the wrong-answer postmortem first
  (data? rule? mapping?), then become either a correction, a fixture, or a bug.
