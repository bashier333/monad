# Weekly pilot call agenda (B-109) — 30 minutes, same slot weekly

1. **The answer (5 min):** pull up this week's lanes. Did the numbers match their gut?
2. **What was wrong (10 min):** walk every open correction + quarantined row that mattered.
   File a wrong-answer postmortem for each wrong figure.
3. **What changed (5 min):** rules added/disabled, aliases added, new imports — and did last
   week's fixes stick?
4. **Friction log (5 min):** where did they stall? Record verbatim in pilot notes.
5. **Next week (5 min):** one upload to add, one correction to verify, one person to invite.
