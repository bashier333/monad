# Friction severity rubric (P-254)

- **Blocker:** pilot cannot proceed without founder help. Fix same day.
- **Annoyance:** pilot proceeds but complains. Fix this week.
- **Nit:** noticed, didn't slow them. Batch monthly.

Log every friction with minute + verbatim quote + severity in pilot notes. Blockers page the
build; nit count measures polish over time.
