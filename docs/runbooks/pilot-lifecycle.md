# Pilot launch checklist (P-301)

1. Agreement signed; org created; owner invited.
2. Concierge call booked with pre-call checklist sent.
3. First upload + mapping on the call; first answer same day.
4. Monday-meeting confirm tracked on /pilots.
5. Week-1 review booked before hanging up.

# Pilot exit checklist (P-302)

1. Export everything (verify download opens).
2. Delete everything on request (confirm in writing within 7 days).
3. Exit interview (20 min, verbatim quotes filed).
4. Findings memo updated; maybes re-contacted.
5. Kill-gate signals reviewed at pilot 3.
