# Changelog process (P-313)

- Who: whoever ships. When: with the PR, before merge.
- Where: `app/changelog/page.tsx` ENTRIES (newest first), plain lines.
- Rule: pilot-visible changes only, plain English, dated. Internal refactors don't qualify
  unless they change behavior pilots feel.
- Monthly: email digest to pilots (manual until Resend automation; template in winback doc).
